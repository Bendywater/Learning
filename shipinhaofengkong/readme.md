# 视频风控

如果是“腾讯视频号风控算法”，而且你说的工作重点是“视频号里的合规性判断”，那你准备时不要把自己学成一个泛算法选手，重点要往“内容安全 + 风控方法论 + 多模态审核”上靠。

1. 内容安全业务理解
     你要先把“审核对象”想清楚，不只是黄赌毒政暴恐。
     视频号场景里常见的是：

  - 违规内容识别：色情、暴力、危险行为、诈骗导流、医疗/金融违规宣传、未成年人不适宜内容
  - 账号/行为风险：批量搬运、营销号、黑产导流、异常互动、团伙作案
  - 多模态一致性问题：标题正常但画面违规，字幕正常但语音违规，封面和正文不一致

  面试里如果你只会说“做个分类器”，会显得太浅。你要能讲“风险类型分层、审核链路分层、处置等级分层”。


2. 多模态算法
     这是视频号风控最关键的算法点之一。
     你至少要掌握：

  - 文本：标题、描述、评论、OCR 字幕、ASR 转写
  - 图像：封面帧、关键帧、目标检测、违规视觉元素识别
  - 视频：时序建模、抽帧、多帧聚合
  - 音频：ASR 后文本审核，必要时加声学特征
  - 多模态融合：early fusion / late fusion / cross-attention 的基本思路

  实战上常见做法不是直接整段视频端到端，而是：

  - 抽关键帧
  - 跑 OCR / ASR
  - 文本模型 + 图像模型分别打分
  - 最后做融合判定或分级召回


3. 风控建模思路
    你要会的不只是分类，还要会“风控链路设计”：

  - 高召回初筛：先尽量别漏掉
  - 高精度复筛：减少误杀
  - 策略 + 模型协同：规则兜底，模型扩展
  - 人审回流：把审核结果重新喂给模型
  - 对抗迭代：黑产会规避关键词、换拼音、谐音、变形图、切片视频

  面试里很常见的问题是：
  “如果业务要求漏判率极低，但误判也不能太高，你怎么设计系统？”
  你最好按“召回层-精排层-复审层-处罚层”回答


4. 样本、标注、评估
     风控岗位很看重这个，因为数据脏、标签难、分布偏。
     重点学：

  - 正负样本构造
  - 长尾类别处理
  - 类别不平衡
  - hard negative mining
  - 主动学习 / 半监督 / 弱监督
  - 评估指标：Precision、Recall、F1、PR-AUC、分层召回率、case 级命中率

  风控场景里通常不能只说 accuracy。
  你要能说：

  - 初筛模型更关注 recall
  - 复筛模型更关注 precision
  - 不同风险级别阈值不同

5. 工程与大数据能力
     这类岗位一般不会只考 notebook。
     你最好能把下面这些讲顺：

  - Python + SQL 是基本盘
  - 能做特征抽取、离线训练、线上推理的闭环
  - 会 Spark/Hive/Flink 一类大数据链路更好
  - 会设计数据回流、样本更新、模型监控

  也就是说，你要表现成“能落地的人”，不只是“会调包的人”。

6. 安全对抗意识
     这是你和普通推荐/分类算法候选人拉开差距的地方。
     你要理解：

  - 黑产会怎么绕过审核
  - 为什么纯规则不够
  - 为什么纯模型也不够
  - 为什么要做人机协同
  - 为什么要做账号、设备、行为、内容联合建模

  如果你能讲出“单内容识别”升级到“账号-内容-关系图谱-行为序列联合识别”，会很加分。
